Embed-test (prototype #14)

Deze pagina embedt de chat-UI in een iframe, zoals een artikel op wtcwoerden.nl dat zou doen. Zonder CSP-beperking van de parent-pagina zie je hieronder de werkende chat.

Plak in een AllUnited-artikel (via het <>-icoon in het intro-/detailblok):

<iframe src="https://wtchat.famstieltjes.nl/" width="100%" height="600" title="WTC Woerden chatbot"></iframe>

Let op: de parent-pagina kan de hoogte niet dynamisch aanpassen (externe scripts worden door AllUnited gestript), dus de chat scrollt intern bij een vaste hoogte.
